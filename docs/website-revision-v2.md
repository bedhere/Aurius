## 后续如何上传资料

1. 管理员登录后进入 **产品公开资料**（`/admin/resources`）。会员原有下载专区独立保留。
2. 点击新增，填写标题及资料类型：产品说明书、安装指南、技术参数、维护说明、WaterMark 证书、安装视频、正式质保条款。
3. 选择对应产品型号。尚未收到文件时，可以直接保存为草稿。
4. 收到文件后，点击该条目的 **编辑 / 补文件**。支持 PDF、JPG、PNG；视频支持 MP4、WebM，单文件最大 150 MB。
5. WaterMark 资料发布前必须填写具体产品、证书编号，以及认证主体、型号和实际适用范围。后台的必填检查不能替代人工核实证书真实性。
6. 勾选发布并保存。资料将在 SUPPORT 和对应产品详情页展示；通用质保条款可不关联单个型号，展示在 `/warranty`。
7. “撤下”后，公开列表和文件访问同时停止。现有会员内部下载资料不会自动变成公开资料。

同一证书适用于多个型号时，分别为各型号关联添加资料，确保消费者能够找到对应型号的范围。安装视频以 HTML 视频播放器展示，支持浏览器按需加载和分段读取。

VISION 场景图在同一后台页面底部上传并点击 **保存品牌场景图**。没有图片时显示品牌文字框架，没有破损图片或开发占位说明。

## 网点资料的后续添加

进入 **经销网点**（`/admin/dealers`），补充公司、城市、服务区域、联系方式、网站、产品类别及原有地图／照片信息。

只有同时满足“启用”“正式授权”且类型为“一级代理商”的记录才会公开。迁移不会将历史示例网点自动认定为已授权。分销商不会显示在公开网点页面。没有公开记录的州使用网络建设中的页面。

## 通用招商表单

- 必填：公司名称、11 位 ABN、州、城市、业务介绍、合作类型、意向产品、目标区域、联系人、电话和邮箱。
- 选填：经营年限、销售网络、当前年销量、预计年销量、网站。
- 当前与预计销量分开，并提示按产品类别填写每年销售数量；销售网络使用自由文本描述数量及合作关系。
- ABN 为格式检查，未接入自动资质审批。申请不会创建已授权采购账户。

## 咨询与售后管理

管理员进入 **咨询与售后**（`/admin/enquiries`），按记录类型、州、状态、咨询／产品渠道类别筛选。可查看完整资料、下载售后附件、修改处理状态和填写内部备注。智能卫浴与净水合作意向分别标记，可同时归入两个渠道。

状态为待处理、审核中、已联系、已结案。状态变化仅用于咨询处理，不授予账户、区域或价格权限。本轮未新增客户进度查询、工单分派、退款或结案自动通知。

表单内容加密留档；售后附件通过管理员接口访问，不能从公开 uploads 地址读取。售后要求订单号或购买凭证二选一，故障照片最多四张，单文件不超过 10 MB。

申请保存后分别尝试发送内部通知和客户确认邮件。SMTP 失败不会丢失申请或要求客户重复提交；后台显示邮件状态，可从邮件日志检查。开发环境只保存邮件日志与预览文件，不能据此认定客户已实际收到邮件。

## 四类账户与价格

使用 `TRADE_PRICING_MODE=role`，默认按当前已审核账户取一套价格：

| 账户 | 内部角色 | 对应价格字段 |
| --- | --- | --- |
| 水工 | `LICENSED_TRADESMAN` / `WATERWORKER` | `waterworkerPrice` |
| 建筑商 | `BUILDER` | `builderPrice` |
| 一级代理商 | `REGIONAL_AGENT` | `dealer1Price` |
| 分销商 | `SUB_DEALER` | `distributor2Price` |

后台商品管理中上述价格可以留空。留空时显示联系询价，不显示零元、不借用其他角色的价格；购物车及结算也拒绝未配置的采购价格。游客仅能读取公开零售价／促销价。未审核账户没有内部价格及采购权限。

未更改现有商品价格数据。本地配置已切到 `role`；部署环境也需配置相同值。原来的 `uniform` / `tiered` 模式保留用于兼容，不适用于本次独立账户价格框架。

本轮的一级代理商与分销商差异包括身份名称、账户介绍、价格和合作信息位置。未新增完整州／城市／邮编业务范围限制及跨级客户资料管理系统。

替换滤芯购买入口按原文“后期增加”保留为后续事项；当前未新增独立滤芯商城。

